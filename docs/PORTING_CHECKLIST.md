# HFSS 项目迁移检查表

本检查表用于把现有 Codex–HFSS 工作流迁移到新的天线、滤波器、功分器、耦合器、封装或互连项目。

## A. 基准模型

- [ ] HFSS 工程能够在 GUI 中正常打开。
- [ ] 基准模型能够完整求解。
- [ ] 材料、边界、端口和激励已人工检查。
- [ ] Design 名称已记录。
- [ ] Setup 名称已记录。
- [ ] Sweep 名称及扫频范围已记录。
- [ ] 端口数量和端口物理含义已记录。
- [ ] 基准曲线与已有结果一致。
- [ ] 原始 `.aedt` 已冻结，自动化脚本不会原地覆盖。

## B. 环境

- [ ] 操作系统版本已记录。
- [ ] HFSS/AEDT 版本已记录。
- [ ] HFSS 安装路径已配置。
- [ ] IronPython、PyAEDT 或其他调用方式已确认。
- [ ] 许可证允许目标并行度。
- [ ] CPU、内存和磁盘能够支撑批量运行。
- [ ] 无界面启动测试通过。

## C. 参数化与几何安全

- [ ] 所有候选变量均能被脚本读取。
- [ ] 每个变量的单位已确认。
- [ ] 每个变量的基准值已记录。
- [ ] 每个变量的物理作用已说明。
- [ ] 允许范围有物理或工艺依据。
- [ ] 联动表达式和依赖变量已列出。
- [ ] 端口、空气盒、边界和参考面会随几何正确更新。
- [ ] 已识别可能造成穿透、悬空、零厚度或端口脱离的参数区间。
- [ ] 缺失变量会使 case 立即失败。

## D. 单次运行链路

- [ ] 基准模型的批处理运行通过。
- [ ] HFSS 能正确关闭，无残留锁文件。
- [ ] 一个参数变更 smoke test 通过。
- [ ] 参数变更已在生成的 `.aedt` 中核实。
- [ ] 输出目录与原始工程隔离。
- [ ] Touchstone 或目标场数据成功导出。
- [ ] profile 成功导出。
- [ ] convergence 成功导出。
- [ ] 运行日志包含开始、结束、状态和错误信息。

## E. 结果解析

- [ ] Touchstone 版本和格式已确认。
- [ ] 端口矩阵映射已验证。
- [ ] 频率单位已验证。
- [ ] MA、DB 或 RI 格式均有明确处理。
- [ ] 网络互易性未被隐式依赖，或该假设已明确说明。
- [ ] 多个交叉点或谐振点时有确定的选择规则。
- [ ] 异常或空结果会被标记为失败。

## F. 指标定义

- [ ] 每个指标的端口、频段、统计量和方向已定义。
- [ ] 波纹在完整频率数组上计算。
- [ ] 最差回波损耗在完整频率数组上计算。
- [ ] 阻带抑制在完整阻带区间计算。
- [ ] 插值和采样策略已记录。
- [ ] 所有 sweep 使用相同指标定义。
- [ ] 指标变更后会重新评估历史 case。
- [ ] 达标阈值有设计需求或文献依据。

## G. 批量实验

- [ ] 每个 case 有唯一 UID。
- [ ] 每个 case 使用独立目录。
- [ ] 批次有机器可读 manifest。
- [ ] manifest 包含参数、状态、路径、指标和错误摘要。
- [ ] 失败 case 被保留。
- [ ] 并行任务数量经过小规模验证。
- [ ] 大规模 sweep 前已完成小批量试运行。
- [ ] 有暂停、恢复或跳过已完成 case 的机制。

## H. 科研设计

- [ ] 每轮实验对应明确假设。
- [ ] 固定变量和变化变量已区分。
- [ ] 参数范围有物理依据。
- [ ] 停止条件已定义。
- [ ] 下一轮决策规则已定义。
- [ ] 单因素扫描未被用来声称不存在交互效应。
- [ ] 局部最佳未被表述为全局最优。
- [ ] 拓扑限制结论有额外物理分析支持。

## I. 收敛与可信性

- [ ] 每个最终候选的网格收敛已检查。
- [ ] 最终候选在更严格设置下重新求解。
- [ ] 结果对扫频分辨率稳定。
- [ ] 边界距离和端口模式合理。
- [ ] 材料损耗模型适用于目标频率。
- [ ] 导体厚度和表面粗糙度处理已说明。
- [ ] 至少对关键尺寸做了局部灵敏度检查。
- [ ] 最终设计进行了制造容差分析，或明确列为未完成。
- [ ] 实测验证状态已明确说明。

## J. 版本与交付

- [ ] 代码和文档已进入独立分支或 PR。
- [ ] 最终候选 `.aedt` 已保留。
- [ ] 最终候选原始结果已保留。
- [ ] 参数、指标和环境配置已保留。
- [ ] 图表可由脚本重新生成。
- [ ] 大型结果有外部存储位置和校验和。
- [ ] README 或主文档说明了运行入口。
- [ ] 已记录已实现功能与规划功能的边界。
- [ ] 已说明结论适用范围和未验证部分。
